# Cboe Global Markets

> Cboe Global Markets operates options, futures, equities, and FX exchanges (including the Cboe Options Exchange, home of the VIX Index and SPX options) and sells market data programmatically through Cboe DataShop and the LiveVol All Access API — a REST suite for live, delayed, and historical options and equities quotes, trades, Greeks, earnings events, scanners, and trade review, secured with OAuth 2.0 via id.livevol.com. Free public delayed-quote JSON endpoints are served from cdn.cboe.com.

Generated by API Evangelist from the artifacts in this repository (no provider-published llms.txt was found; /llms.txt is 404 on www.cboe.com, datashop.cboe.com, and api.livevol.com).

## APIs

- [Cboe LiveVol All Access API](https://api.livevol.com/v1/docs/): REST API at https://api.livevol.com/v1 — Market at a Glance, Time and Sales, Events (earnings), Analytics (trade review), Reference, and Scans and Alerts endpoint groups. OAuth 2.0 (client_credentials or authorization_code) via https://id.livevol.com/connect/token; bearer tokens, 3600s lifetime; points-metered usage.
- [Cboe Delayed Quotes API](https://www.cboe.com/delayed_quotes/): unauthenticated JSON at https://cdn.cboe.com/api/global — e.g. /delayed_quotes/quotes/_SPX.json and /delayed_quotes/options/_SPX.json for delayed quotes and full option chains with IV and Greeks.
